╚══════════════════════════════════════════════════════════════════════════╝

  Start Development Environment
  ┌────────────────────────────────────────────────────────────────────────┐
  │ make up          OR    docker compose -f docker-compose.dev.yml up -d │
  └────────────────────────────────────────────────────────────────────────┘

  Enter Container
  ┌────────────────────────────────────────────────────────────────────────┐
  │ make shell       OR    docker exec -it zion-dev bash                │
  └────────────────────────────────────────────────────────────────────────┘

  View Logs
  ┌────────────────────────────────────────────────────────────────────────┐
  │ make logs        OR    docker compose -f docker-compose.dev.yml logs  │
  └────────────────────────────────────────────────────────────────────────┘

  Stop Everything
  ┌────────────────────────────────────────────────────────────────────────┐
  │ make down        OR    docker compose -f docker-compose.dev.yml down  │
  └────────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════════╗
║                    🔨 BUILD COMMANDS (Inside Container)                  ║
╚══════════════════════════════════════════════════════════════════════════╝

  Configure (Debug)
  ┌────────────────────────────────────────────────────────────────────────┐
  │ cmake --preset debug                                                   │
  └────────────────────────────────────────────────────────────────────────┘

  Build
  ┌────────────────────────────────────────────────────────────────────────┐
  │ cmake --build build/debug --parallel                                   │
  └────────────────────────────────────────────────────────────────────────┘

  Run Tests
  ┌────────────────────────────────────────────────────────────────────────┐
  │ ctest --test-dir build/debug --output-on-failure                       │
  └────────────────────────────────────────────────────────────────────────┘

  Run Server
  ┌────────────────────────────────────────────────────────────────────────┐
  │ ./build/debug/zion-server                                            │
  └────────────────────────────────────────────────────────────────────────┘
